Then open:

Important
The app expects a PostgreSQL database and a valid POSTGRES_DSN in .env
(the tables are created automatically on start).
An OpenRouter API key is needed only for "Generate from PDF"; every study
mode works without it.
If the virtual environment is already active, you can skip the activation step.

Run the tests
python -m unittest discover -s tests -t .
node --test tests/js
